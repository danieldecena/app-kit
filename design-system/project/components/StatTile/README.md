# StatTile

One figure worth checking at a glance, with a mono uppercase key and an optional 0 to 1 meter.

- Key in `label` (mono 11, `ink-soft`), value in `figure` (SF Pro Rounded 28 bold, tabular figures, as in Health), unit in `footnote` `ink-soft`.
- `surface` fill, `radius-md`, `space-5`/`space-6` padding. The meter is `accent` on `accent-wash`.
- `attention` draws a 1.5px `accent` ring: the tile needs the person. Never a colored left border.
- Lay tiles in a wrapping row of 2 to 4; do not lead a screen with tiles unless the figures are its point.
