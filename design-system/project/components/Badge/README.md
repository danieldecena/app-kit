# Badge

A short uppercase tag of metadata or state: "4K", "HDR", "STOCKED", "SYNCED".

- Mono `label` style (11px, 600, uppercase, +0.06em), `radius-sm`, `3px 8px` padding.
- `neutral` (sunk fill) and `hollow` (edge outline) carry plain facts. The tinted tones pair a wash with its ink: `accent`, `ok`, `warn`, `bad`.
- One or two words. If it needs a sentence, use Flag.
