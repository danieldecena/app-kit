# StatTile

One figure worth checking at a glance, with a mono uppercase key and an optional 0 to 1 meter.

- Key in `label` (mono 11, `ink-soft`), value in `value` (mono 28, tabular figures), unit in `footnote` `ink-soft`.
- `surface` fill, `radius-md`, `space-5`/`space-6` padding. From Charts Tab's instrument panel and Footage Review Board.
- `attention` draws a 1.5px `signal` ring and turns the meter `signal`: the tile needs the person. Never a colored left border.
- Lay tiles in a wrapping row of 2 to 4; do not lead a screen with tiles unless the figures are its point.
