# Flag

An inline status callout: a glyph plus one sentence saying what is wrong and what to do.

- `warn`: `warn-ink` on `warn-wash` with a `warn` outline. `bad`: `bad` on `bad-wash`. `signal`: something needs the person.
- Always a glyph and words, never color alone. Sentence case, no apology: "Card is 94% full. Offload before the next shoot."
- 12px/600 sans, `radius-sm`. The consumer provides `tone` and the sentence.
